🧱 Networking Layers Overview

Networking stacks abstract communication into layers. The OSI model is conceptual; TCP/IP model maps to real-world protocols.

OSI Model

  • Layer 7: Application (HTTP, gRPC, DNS)
  • Layer 6: Presentation (TLS, encryption)
  • Layer 5: Session (sockets, RPC sessions)
  • Layer 4: Transport (TCP, UDP)
  • Layer 3: Network (IP)
  • Layer 2: Data Link (Ethernet, Wi-Fi)
  • Layer 1: Physical (cables, fiber, radio)

TCP/IP Model

  • Application
  • Transport
  • Internet
  • Link

Key Concepts

  • IP addressing, CIDR notation, IPv4 vs IPv6.
  • Ports (0-65535), ephemeral ports.
  • DNS resolution (recursive vs authoritative).

Latency Components

  • Propagation delay (distance).
  • Serialization delay (packet size / link speed).
  • Queuing delay (congestion).
  • Processing delay (routers, firewalls).

🚚 Transport Protocols

Transport protocols define how data is delivered end-to-end.

TCP (Transmission Control Protocol)

Reliable
  • Connection-oriented, reliable delivery.
  • Three-way handshake, SYN backlog, FIN/ACK.
  • Flow control: sliding window, congestion control (AIMD, CUBIC, BBR).
  • Head-of-line blocking (HOLB) due to ordering.

UDP (User Datagram Protocol)

Best Effort
  • Connectionless, unordered, unreliable.
  • Used for low latency (VoIP, streaming, DNS).
  • Application implements reliability if needed.

QUIC

Modern
  • Runs over UDP; integrated TLS 1.3.
  • 0-RTT connection resumption, multiplexed streams without HOLB.
  • Powers HTTP/3, improved performance on lossy networks.

Connection Management

  • Keep-alive timeouts (prevent idle disconnects).
  • SYN flood protection (SYN cookies, backlog tuning).
  • Ephemeral port exhaustion (NAT, high concurrency).

🌐 HTTP & Web Delivery

Understanding HTTP evolution helps build high-performance APIs and web applications.

HTTP/1.1

  • Persistent connections, pipelining (rarely used).
  • Head-of-line blocking due to sequential requests.
  • Use keep-alive and connection pooling.

HTTP/2

Multiplexed
  • Binary framing, multiplexed streams over single TCP connection.
  • Header compression (HPACK).
  • Server push (optional; often disabled due to complexity).

HTTP/3 (QUIC)

  • Runs over QUIC (UDP) to avoid TCP head-of-line blocking.
  • Faster handshake (1-RTT), improved mobile performance.
  • Requires proxy/load balancer support.

API Design

  • REST vs gRPC vs GraphQL trade-offs.
  • Pagination strategies, compression, caching headers.
  • Versioning, retry semantics, idempotency.

Web Performance

Frontend
  • CDNs, caching headers, service workers.
  • Minify assets, preconnect/prefetch, inline critical CSS.
  • Monitor Core Web Vitals (LCP, FID, CLS).

🚦 Routing & Load Balancing

Route traffic across networks and services based on policies, capacity, and health.

Routing Basics

  • Routers use routing tables, protocols (OSPF, BGP).
  • Default gateways, static routes, route summarization.
  • Network Address Translation (NAT) for IPv4 scarcity.

Load Balancing Algorithms

Service
  • Round robin, least connections, weighted, IP-hash.
  • Application-aware (L7) vs connection-level (L4).
  • Health checks, outlier detection, circuit breakers.

Global Traffic Management

  • Geo-DNS, Anycast routing.
  • Primary/secondary regions, active-active vs active-passive.
  • Failover detection, DNS TTL tuning.

Content Delivery Networks

  • Edge caching for static/dynamic content.
  • Origin shield, cache invalidation, signed URLs.
  • Monitor cache hit ratio, TTFB.

🔐 Network Security & TLS

Security spans encryption, access control, and protecting against network-based attacks.

TLS Basics

  • TLS handshake (1.2 vs 1.3), cipher suites.
  • Certificates, certificate authorities, OCSP stapling.
  • Perfect forward secrecy (ECDHE).

Authentication & Authorization

  • Mutual TLS (mTLS), API keys, OAuth2, JWTs.
  • Network policies (security groups, firewalls).
  • Zero trust networking, service mesh sidecars.

Attacks & Mitigation

  • DDoS – scrubbing, rate limiting, CDN absorption.
  • Man-in-the-middle – enforce HTTPS, HSTS, certificate pinning.
  • DNS poisoning – DNSSEC, secure resolvers.

Secure Protocols

  • SSH for remote access, SFTP for secure file transfer.
  • IPsec VPNs, WireGuard for site-to-site/workforce access.
  • Use application-layer encryption when network untrusted.

🛠️ Diagnostics & Tools

Diagnose network issues using layered tools and observability.

Foundational Tools

  • ping – reachability & latency.
  • traceroute / mtr – path and hop latency.
  • nslookup / dig – DNS resolution.

Traffic Analysis

  • tcpdump, Wireshark for packet capture.
  • NetFlow/sFlow for network flow statistics.
  • Browser DevTools for HTTP trace.

Performance Monitoring

  • APM tools for service latency (Datadog, New Relic).
  • Synthetic probes (Pingdom, Catchpoint).
  • Network telemetry (Prometheus node exporter, cloud metrics).

Observability Practices

  • Instrument services with distributed tracing (OpenTelemetry).
  • Log request IDs, correlation IDs to trace across services.
  • Alert on latency percentiles, error codes, saturation.

🚨 Common Networking Failure Modes

Most production outages stem from a small set of recurring lapses. Build runbooks and guardrails for these scenarios.

Packet Loss & Bufferbloat

Latency Surge
  • Congested queues or oversized buffers cause retransmits and multi-second tail latency.
  • Impact: Throughput collapse, video/audio glitches, TCP timeouts.
  • Prevention: Monitor retransmit %, deploy AQMs (FQ-CoDel), right-size buffers, enable BBR/QUIC where possible.

MTU & Fragmentation Mismatch

Blackhole
  • Path MTU differs across links; ICMP blocked so DF packets vanish.
  • Impact: API calls hang, TLS handshake fails, VPN instability.
  • Prevention: Enable PMTUD, allow ICMP type 3/4, set MSS clamping on tunnels and load balancers.

DNS & TTL Drift

Resolution Failures
  • Stale records, misconfigured split-horizon DNS, or negative caching hide topology changes.
  • Impact: Traffic routed to decomissioned hosts, partial outages by geography.
  • Prevention: Automate DNS updates, monitor NXDOMAIN/ SERVFAIL, keep low TTLs during migrations.

TLS & Certificate Expiry

Security
  • Forgotten certificates or mismatched SANs break HTTPS/mTLS handshakes.
  • Impact: Outages at midnight UTC, mobile app failures, regulatory incidents.
  • Prevention: Automate issuance (ACME), alert 30/7/1 days before expiry, centralise inventories.

Route Leaks & BGP Flaps

Global Impact
  • Upstream advertises incorrect prefixes or loses redundancy.
  • Impact: Regional reachability loss, asymmetric routing, increased latency.
  • Prevention: Use RPKI/ROV, multi-homing, route monitors (ThousandEyes, RIPE RIS) with alerting.

Firewall / ACL Drift

Change Risk
  • Manual rule edits or policy drift block required ports or health checks.
  • Impact: Sudden service isolation, failing load balancer probes.
  • Prevention: Use infrastructure-as-code for network policies, run diff + automated tests, log rejects centrally.
